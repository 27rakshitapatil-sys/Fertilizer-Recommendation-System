# 🌱 Fertilizer Recommendation System

A machine learning-based web app that recommends the best fertilizer for crops based on soil type, crop type, and nutrient levels.

🔗 **Live Demo:** https://fertilizer-recommendation-system-k8ob.onrender.com/  
💻 **GitHub:** https://github.com/27rakshitapatil-sys/Fertilizer-Recommendation-System

## Features
- Predicts the most suitable fertilizer based on soil and crop data
- Simple web interface built with Flask
- Trained on real agricultural data

## Tech Stack
Python, Flask, scikit-learn, HTML/CSS

## How to Run Locally
```bash
git clone https://github.com/27rakshitapatil-sys/Fertilizer-Recommendation-System.git
cd Fertilizer-Recommendation-System
pip install -r requirements.txt
python app.py
```
